## 🚀 How to Deploy 100% Freely on GitHub Pages

### Method 1: Web Browser (Drag & Drop — No Git CLI Required)
1. Go to [github.com](https://github.com) and log in as **`maheshk3`**.
2. Click the **`+`** icon &rarr; **New repository**.
   - **Repository name**: `maheshk3.github.io`
   - **Visibility**: **Public**
   - Click **Create repository**.
3. Click **Add file** &rarr; **Upload files**.
   - Drag and drop:
     - `index.html`
     - `css/` folder (with `style.css`)
     - `js/` folder (with `script.js`)
     - `README.md`
   - Click **Commit changes**.
4. Go to **Settings** &rarr; **Pages** &rarr; Branch: select `main` and `/(root)` &rarr; Click **Save**.
5. Your portfolio is live for free at:
   👉 **`https://maheshk3.github.io/`**
